# ExCalendar — Telegram бот для записи на индивидуальные тренировки

## Возможности
- клиенты видят доступные часы на ближайшие дни и бронируют слот (1 час);
- тренер (единственный администратор) получает запрос с кнопками `Принять/Отклонить`;
- при отклонении тренер может указать причину (необязательно) — клиент увидит её в ответе;
- клиенты отменяют запись из кнопки «🗓 Мои записи» (можно указать причину), тренер получает уведомление;
- у тренера есть только кнопка «📘 Записи тренера»: он видит сводку всех предстоящих слотов и при необходимости может отменить подтверждённую тренировку (с указанием причины или без неё);
- прошедшие тренировки автоматически удаляются из истории, свободные слоты снова становятся доступными;
- при подтверждении слот автоматически помечается занятым, клиенту приходит уведомление;
- **все данные хранятся в MySQL базе данных**;
- **веб-интерфейс**: календарь для клиентов и админ-панель для тренера.

## Быстрый старт
1. Установите Python 3.11+ и создайте виртуальное окружение:
   
```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   
```
2. Настройте MySQL базу данных:
   - Создайте базу данных `excalendar`
   - Скопируйте `config.env.sample` в `config.env` и заполните:
     - `TELEGRAM_BOT_TOKEN` — токен вашего бота;
     - `INSTRUCTOR_CHAT_ID` — Telegram ID тренера (получить через @userinfobot);
     - Настройки подключения к MySQL (`MYSQL_HOST`, `MYSQL_PORT`, `MYSQL_USER`, `MYSQL_PASSWORD`, `MYSQL_DATABASE`);
     - При необходимости измените рабочие дни/часы и горизонт бронирования.
3. Запустите бота:
   
```
   python -m src.bot
   
```

## Веб-интерфейс
Запустите веб-сервер параллельно с ботом:
```
python -m src.web
```

- **Календарь для клиентов**: http://localhost:5000/
- **Панель тренера**: http://localhost:5000/admin

## Как работает бот
- `/start` — бот показывает главное меню с кнопками:
  - `📅 Записаться` — открыть календарь ближайших свободных слотов;
  - `🗓 Мои записи` — список активных заявок с кнопками отмены (и полем для причины);
  - `📘 Записи тренера` — доступно только инструктору, список всех грядущих заявок.
- Из раздела `📘 Записи тренера` инструктор может отменить любую ещё актуальную тренировку и при желании указать причину — клиент сразу получит уведомление.
- Календарь листается стрелками `◀️ / ▶️`, поэтому можно выбрать дату дальше стандартных 2 недель (горизонт задаётся `BOOKING_HORIZON_DAYS`).
- `/help` — краткая инструкция (также доступна из кнопок).
- После выбора даты и времени клиент видит статус «ожидает подтверждения», а тренеру
  приходит карточка заявки.
- Тренер подтверждает или отклоняет запрос кнопками в чате. Клиенту сразу приходит результат.

## Настройки расписания
Параметры `.env`:
- `TIMEZONE` — часовой пояс (по умолчанию `Europe/Moscow`);
- `WORKING_DAYS` — дни недели через запятую (`mon,tue,wed,thu,fri,sat`);
- `WORK_START_HOUR` / `WORK_END_HOUR` — первая и последняя граница слотов;
- `BOOKING_HORIZON_DAYS` — на сколько дней вперёд показывать календарь (до 30).

Ежедневные слоты генерируются автоматически с шагом 1 час.

## Структура проекта
```
src/
  bot.py            # запуск Telegram-бота и обработчики
  config.py         # чтение .env и настройка расписания
  booking_store.py  # хранение и проверка заявок (MySQL)
  keyboards.py      # inline-клавиатуры Telegram
  web.py           # веб-интерфейс (Flask)
templates/
  index.html       # календарь для клиентов
  admin.html       # админ-панель тренера
data/
  bookings.json    # (устарело, теперь MySQL)
```
